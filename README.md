# GeoVisionTagger

A Mobile Application for Capturing Images with Spatio-Temporal Data and Visualization through Kernel Density Estimation

### Core Features

* **Unified Data Collection:** Features real-time image capture that automatically embeds precise geographical (latitude/longitude) and temporal (time) data into every file.
* **On-Device Image Annotation:** Provides robust, detailed image tagging and labeling tools directly within the mobile interface.
* **Advanced Spatial Visualization:** Includes an interactive mapping system that allows researchers to visualize data distribution and spatial patterns in real-time.
* **Heatmap Generation:** Automatically generate accurate heatmaps from the collected image coordinates.

  ### Dataset Generation
  The project can be exported as a dataset through the export button which is on the top-right button on the app if a project is open.
  The exported project will be stored in a zip file which can be extracted to obtain the dataset.

  The dataset will contain the following:
  * **Images Folder:** All images that are within the project
  * **Annotation Folder:** Visual images that show the annotations of each layer of annotation for each image
  * **COCO JSON File: ** Contains all annotation data of each image in COCO JSON format.
  * **GeoJSON File: ** Contains all geodata of all project images
  * **Generated Heatmap: ** A heatmap generated by the application.
